# GRIB Weather Provider roadmap

## Support the expanding GRIB catalogue

- [ ] Verify that supported forecasts from new Downloader sources and from manually imported GRIB runs can serve point forecasts through the Signal K Weather API.
- [ ] Verify the Weather API path in [Weather Map](https://github.com/macjl/signalk-weather-map) alongside its planned direct GRIB dataset access. Users should be able to choose either source according to the forecast they need.
